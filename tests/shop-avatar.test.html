Avatar de l'assistant servi par la boutique (window.__PARTSMIND_CONFIG__.avatar)

L'avatar posé sur chaque message de l'assistant peut porter le logo du marchand. Le BOUTON FLOTTANT, lui, garde la marque EveryParts : il annonce le produit, pas le marchand. Trois scénarios : aucune configuration (la marque), une URL (une image), et une valeur d'injection — qui doit rester une adresse, jamais du balisage.
